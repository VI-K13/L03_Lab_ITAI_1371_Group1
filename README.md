## Project Overview

This lab explores the complete machine learning workflow, from data preparation and feature selection to model training, evaluation, and interpretation. The project uses the Wine dataset to compare classification models and examine how feature choices can affect model performance.

The lab also focuses on understanding the differences between supervised, unsupervised, and reinforcement learning and connecting these approaches to real-world applications.

## What We Worked On

- Explored and prepared the Wine dataset
- Examined class distribution and feature correlations
- Split the data into training and testing sets
- Trained Logistic Regression and Decision Tree models
- Compared model performance using accuracy and classification reports
- Interpreted results using a confusion matrix
- Experimented with different feature combinations
- Reviewed supervised, unsupervised, and reinforcement learning
- Connected machine learning concepts to real-world applications such as cybersecurity

## Key Result

The original Logistic Regression model achieved 88.9% accuracy, compared with 83.3% for the Decision Tree. After experimenting with a different feature combination, the Logistic Regression model reached 91.7% accuracy.
